# Stage 3 real-browser review evidence — tasks 9.1–9.3

Date: 2026-09-21. Reviewer: stage 3 independent review task (fresh, no Apply inheritance).

## Reproduce and archive

From the repository root, rebuild the production artifact and run the pinned
browser harness:

```sh
npm --prefix apps/web run build
cd openspec/changes/redesign-web-visual-system/evidence/browser
npm ci
npm run review
```

`VELA_BROWSER_PORT` overrides the local static-server port (default `4517`)
and `VELA_BROWSER_CHROME_CHANNEL` overrides Playwright's Chrome channel
(default `chrome`, the system Google Chrome). For example:

```sh
VELA_BROWSER_PORT=4518 VELA_BROWSER_CHROME_CHANNEL=chrome npm run review
```

The runner finds the repository with `git rev-parse --show-toplevel`, so the
same commands work after this Change is archived: `cd` to that archived
Change's `evidence/browser` directory before `npm ci` and `npm run review`.
It starts and closes its own static `apps/web/dist` server; no API service is
started. Every `/api/**` request is intercepted in the browser by the fixed
`fixtures.mjs` data, so the run never writes `vela.db`. `node_modules/` is
intentionally local installation output and is not evidence.

`review-results.json` is regenerated with the complete check list plus the
execution timestamps, `git HEAD`, `apps/web` worktree-diff fingerprint,
production-dist file manifest/hash, runner/fixture SHA-256 hashes, browser
configuration, and screenshot hashes. The screenshots in this directory are
regenerated by the same run and are listed in that result record.

## Defect found and fixed by this review

- `.detail-page dt` (16px meta leading, 8px bottom margin) overrode
  `.compact-list dt` (20px shared row leading) on every detail page,
  violating the card-type-scale compact-list exception ("both dt and dd
  MUST use --leading-body-card: 20px"). The concentrated static test only
  asserted the base rule body, so the cascade override escaped static
  checks; the real-browser check caught it. Fix: `.detail-page .compact-list
  dt { line-height: var(--leading-body-card); margin-bottom: 0; }` in
  `apps/web/src/styles.css`. Re-verified 20px computed on all detail pages
  at all sizes, and the complete Web gate re-passed afterwards.
